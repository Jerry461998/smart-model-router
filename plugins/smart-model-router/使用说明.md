# 智慧模型路由 使用说明

这是一个 Codex 插件，用来在写代码时自动把工作分给合适的模型：

- **GPT-6 Luna**：查找、机械修改、常规核对
- **GPT-6 Sol Medium**：普通功能开发和中等难度排查
- **GPT-6 Sol High**：架构、生产、并发、一致性等复杂判断
- **GPT-6 Astra**：只有明确要求，或 Sol 连续两次仍不够时才升级

从 GitHub 下载仓库 ZIP 并解压后，进入 `plugins/smart-model-router` 文件夹，按下面操作即可；也可以单独分享这个插件文件夹的压缩包。

---

## 发给对方前，请先看

- 对方需要已经安装并登录 **Codex**（桌面版或命令行都可以，但安装时电脑里要能运行 `codex` 命令）。
- 当前安装脚本面向 **Windows**。
- 安装会改对方的 Codex 全局设置，并把默认主模型改成 **GPT-6 Sol Medium**。卸载时会恢复安装前记录的设置。
- 对方账号需能使用 GPT-6 Luna 和 Sol；模型开放情况受 Codex 版本、订阅和工作区设置影响。
- 分享时只需公开仓库链接，或单独打包 `plugins/smart-model-router` 文件夹；不要把个人配置和备份打包进去。

---

## 一、安装前检查

1. 解压到任意目录，例如桌面。不要直接在压缩包里双击。
2. 打开 PowerShell 或终端，输入：

```powershell
codex --version
```

能显示版本号即可。

3. 可选：如果电脑里有 Python 3，分类会更稳；没有的话，插件仍可按内置规则工作。

---

## 二、安装

### 方法 A：双击安装（推荐）

解压后双击 `安装.bat`，等窗口出现 `"status": "installed"` 后关闭。

### 方法 B：命令安装

在解压出来的 `smart-model-router` 文件夹里运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

安装成功后，**必须新开一个 Codex 任务**，插件和技能才会生效。正在进行的旧任务不会自动带上。

---

## 三、安装后怎么用

之后正常让 Codex 写代码、改代码、排查问题即可。它会在软件开发任务里自动路由，并在回复里给出类似这样的摘要：

```text
Routing:
- Explore → Luna low
- Implement → Sol medium
- Verify → Luna medium
```

你也可以直接说：

- `用智慧模型路由来实现并核对这个改动`
- `这次只使用 Luna`
- `不要使用 Astra`
- `这个问题用 Sol`
- `先别改代码，只分析`

---

## 四、它会改电脑上的哪些地方

安装程序会：

1. 把插件复制到 `%USERPROFILE%\plugins\smart-model-router`
2. 注册到个人插件市场，并执行 `codex plugin add smart-model-router@personal`
3. 写入 6 个自定义智能体配置到 `%USERPROFILE%\.codex\agents\`
4. 在 `%USERPROFILE%\.codex\config.toml` 里加入受管配置，默认主模型改为 GPT-6 Sol Medium
5. 在 `%USERPROFILE%\.codex\AGENTS.md` 里加入一段自动路由规则
6. 在改配置前先做时间戳备份，备份在 `%USERPROFILE%\.codex\smart-model-router\backups`

不会删除对方原来的其他插件、技能或项目代码。

---

## 五、查看状态、暂时关闭、卸载

以下文件都在解压目录里，也可以到安装后的 `%USERPROFILE%\plugins\smart-model-router` 里运行。

| 想做的事 | 双击 | 命令 |
|---|---|---|
| 查看是否装好 | `查看状态.bat` | `.\scripts\status.ps1` |
| 暂时关掉自动路由 | `关闭自动路由.bat` | `.\scripts\disable.ps1` |
| 重新打开 | `重新开启.bat` | `.\scripts\enable.ps1` |
| 完全卸载 | `卸载.bat` | `.\scripts\uninstall.ps1` |

关闭或卸载后，同样需要 **新开一个 Codex 任务** 才会生效。

卸载只会移除本插件相关项，并恢复安装前记录的主模型设置。如果某个智能体配置在安装后又被改过，卸载时会保留那个文件并报告路径。备份不会自动删除。

## 六、常见问题

**装完没有变化**

先确认安装窗口里是 `installed`，然后新开 Codex 任务，不要继续用旧任务。

**提示找不到 `codex`**

说明命令行里没有 Codex。先安装/修复 Codex，保证 `codex --version` 能用，再重新运行 `安装.bat`。

**插件列表里看不到**

运行 `查看状态.bat`，确认 `pluginListEvidence` 里有 `smart-model-router@personal`。

**不想改默认模型，只想试用**

目前安装脚本会把默认主模型改成 GPT-6 Sol Medium。如果不接受这一点，先不要安装；需要的话可以再要一份“不改默认模型”的安装方式。

**Mac / Linux 能不能用**

插件内容和规则可以看，但当前安装/卸载脚本是 Windows PowerShell，不能直接双击安装。

---

## 七、给对方的最短说明

请解压后双击 `安装.bat`。看到 installed 后，新开一个 Codex 任务再开始用。若要删除，双击 `卸载.bat`。
